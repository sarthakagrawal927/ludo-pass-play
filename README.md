# Ludo — Pass & Play

A mobile-first, local multiplayer Ludo game for two to four people sharing one
device. It runs as an installable PWA, keeps game state in local storage, and
does not require accounts or a backend.

## Highlights

- Pass-and-play setup for two, three, or four players
- Pure TypeScript game engine with Vitest coverage
- Responsive SVG board, animated pieces, and post-game stats
- Offline support through the PWA service worker

## Development

```bash
pnpm install
pnpm dev
pnpm build
pnpm vitest
```
